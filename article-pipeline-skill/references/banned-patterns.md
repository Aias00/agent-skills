# 禁用句式清单

检查器：`technical-article-review/scripts/check_banned_scaffolding.py`

## 自动检查的模式（硬门）

| 模式 | 正则 | 说明 |
|------|------|------|
| 不是……而是…… | `不是[^。！？\n]{0,80}而是` | 对比脚手架 |
| 不只是……而是…… | `不只是[^。！？\n]{0,80}而是` | 升级版对比脚手架 |
| 不……而是…… | `不[^\n。！？]{0,60}?而是` | 懒匹配版 |
| 而不是 | `而不是` | 直排对比 |
| 如果只 | `如果只` | 假设式分析开场 |
| 也就是说 | `也就是说` | 过度解释转折 |
| 这一步很关键 | `这一步很关键` | 分析腔过渡 |

命中即硬门：pipeline 第一步失败，必须修复才能继续。

## 人工把关的模式（检查器暂不覆盖）

- `不是……是……`（缺「而」的变体）——加正则会误杀简单否定句（如「不是故意的」），保持人工判断
- `缺的不是 X，是 Y` 类标题句式
- `不替代……而是……` 类变体

## 改写方法

命中的句子改写原则：**保留信息，去掉对比结构，直接陈述。**

| 原文 | 改写 |
|------|------|
| 这不是「又套了一层」，而是重新设计 | 它直接重做了这段设计 |
| 不是向量检索，是图检索 | 向量检索的边界和图检索的答案 |
| 缺的不是工具，是管理 | 工具够用了，管理跟不上 |
| 多数 Agent 不裁剪，Reasonix 先裁再摘要 | 直接描述 Reasonix 的做法 |

## 相关

- 检查器修复记录：`不[^。！？]{0,60}而是` 曾用贪婪匹配 `{0,60}`，会吞掉「而是」导致漏检，已改懒匹配 `{0,60}?`
- 修模式后跑 `python3 scripts/check_banned_scaffolding.py --input <file>` 验证
