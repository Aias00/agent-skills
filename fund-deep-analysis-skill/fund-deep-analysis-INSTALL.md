## 🎯 使用场景

### 单基金深度分析

```
适用场景：

• 评估基金业绩、持仓、风险

### 组合整体评估

```
适用场景：
• 分析多个基金组成的组合
• 评估资产配置健康度

• 风险评估和预警

不适用场景：
• 简单净值查询
• 快速价格比较
```

## 🚀 核心方法论

### 单基金分析6步骤

```
1. 基本信息提取
   → 基金全名、净值、费率、交易状态

2. 持仓分析
   → 前10大持仓 → 集中度 → 特点

3. 业绩表现
   → 8个时间段 vs 同类 vs 沪深300

4. 风险评级
   → R1-R5等级 + 5大风险来源

5. 综合评价
   → 7维度评分（100分制）

6. 投资建议
   → 增持/持有/减持决策
```

### 组合分析6步骤

```
1. 数据抓取（循环web_fetch）
2. 单基金分析
3. 组合整体评估
4. 组合评级（6维度 → A-E级）
5. 优化方案设计
6. 风险警示和免责声明
```

### 风险评估体系（R1-R5）

```
R5 - 极高风险
   行业单一、集中度>70%、小盘股/新兴市场

R4 - 高风险
   集中度40-70%、单一行业50-80%、QDII/科技/生物

R3 - 中高风险
   集中度25-40%、行业分散3-5个、混合配置

R2 - 中等风险
   宽基指数、集中度<25%、包含防守资产

R1 - 低风险
   债券/货币基金、保本/固定收益
```

## ⚠️ 重要提醒

### 此skill的局限性

1. **数据时效性**
   - 数据抓取是一次性的，非实时更新
   - 净值、仓位、排名可能已变化

2. **分析深度**
   - 基于公开数据，缺乏内部信息
   - 无法分析基金经理决策逻辑
   - 无法分析市场情绪/博弈

3. **预测能力**
   - 不承诺未来业绩
   - 不保证历史持续
   - 不排除黑天鹅事件

4. **不替代专业顾问**
   - 不替代专业投资顾问
   - 不具备职业投资资质
   - 不能承担投资责任

### 使用建议

```
✅ 适合：
   - 投资金额 < ¥10,000（个人小资金）
   - 学习基金分析方法
   - 自主投资决策参考

⚠️ 不适合：
   - 投资金额 > ¥10,000（大额投资）
   - 依赖建议全盘接受
   - 不愿了解投资风险

❌ 严禁：
   - 向他人推荐投资决策
   - 承诺收益或安全

### Q1: 如何使用这个skill?

- "分析基金016452" → 单基金分析
- "分析我的基金组合" → 组合分析（需提供基金代码和持仓）

### Q2: 数据来源是什么?

天天基金网: https://fund.eastmoney.com

### Q3: 分析报告保存在哪里?

```
单基金分析:
investment/fund_deep_analysis_{基金代码}_{日期}.md

组合分析:
investment/portfolio_deep_analysis_{日期}.md
```

### Q4: 可以自动分析吗?

可以，但需要：
1. 提供基金代码列表
2. 提供持仓金额/占比
3. 流程：数据抓取 → 分析 → 生成报告

### Q5: 分析结果可以完全相信吗?

不可以。分析基于历史数据和公开信息，不承诺未来业绩，不构成投资建议。投资者需自主判断，风险自负。
