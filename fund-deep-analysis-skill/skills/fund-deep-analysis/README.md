## 🎯 适用场景

### 使用场景

✅ **单基金深度分析**
- 深入研究一只基金
- 评估基金业绩、持仓、风险
- 决定是否增持/持有/减持

✅ **组合整体评估**
- 分析多个基金组成的组合
- 评估资产配置健康度
- 设计优化方案

✅ **基金风险预警**
- 识别过度集中风险
- 评估流动性风险
- 预估最大回撤

❌ **不适合的场景**
- 查询单一净值 → 使用 `fund-query` skill
- 基金排名 → 使用 `fund-query` skill
- 简单价格查询 → 使用 `fund-query` skill

## 🚀 使用流程

### 单基金分析流程

```
用户请求 → 数据抓取 → 深度分析 → 生成报告
           (web_fetch)  (5大维度)  (MD文件)
```

**步骤示例**：

1. **用户请求**
   ```
   "分析基金016452"
   ```

2. **数据抓取**
   ```bash
   web_fetch(url="https://fund.eastmoney.com/016452.html", extractMode="markdown", maxChars=15000)
   ```

3. **深度分析**
   - 基本信息
   - 持仓分析（前10大 -> 特点 -> 亮点/风险）
   - 业绩表现（各时段 vs 同类 vs 沪深300）
   - 风险评级（风险等级 + 风险来源 + 回撤估算）
   - 综合评价（7维度评分）
   - 投资建议（增持/持有/减持理由）

4. **生成报告**
   ```
   保存至：investment/fund_deep_analysis_016452_20260303.md
   ```

### 组合分析流程

```
用户请求 → 数据抓取（多只）→ 单基金分析 → 组合评估 → 优化方案
           (web_fetch × N)          (汇总分析)    (设计计划)
```

**步骤示例**：

1. **用户请求**
   ```
   "分析我的基金组合"
   -> 提供基金代码 + 持仓金额
   ```

2. **数据抓取**（循环）
   ```bash
   # 对每只基金抓取数据
   for fund in [list]:
       web_fetch(url=f"https://fund.eastmoney.com/{fund}.html", ...)

   # 验证数据完整性
   ```

3. **单基金分析**（对每只基金）
   ```
   使用单基金分析模板，生成每只基金的分析
   ```

4. **组合评估**（汇总）
   - 资产配置分析（各类占比）
   - 组合收益分析（加权收益计算）
   - 风险暴露分析（市场/行业/货币）
   - 组合评级（综合评分）

5. **优化方案**
   - 短期优化（1-2个月）：具体操作清单
   - 中期优化（3-6个月）：定投策略
   - 长期优化（1-3年）：目标配置

6. **生成报告**
   ```
   保存至：investment/portfolio deep analysis_20260303.md
   ```

## 📊 核心方法

### 数据抓取方法

```bash
# 基础抓取
web_fetch(
  url="https://fund.eastmoney.com/{基金代码}.html",
  extractMode="markdown",
  maxChars=15000
)

# 抓取并验证
response = web_fetch(url=...)
# 检查：基金名称、净值、持仓、业绩、排名
```

### 单基金分析维度

```
1. 基本信息提取
   • 基金全名、净值、费率、交易状态

2. 持仓分析
   • 前10大持仓列表
   • 集中度（前10占比）
   • 行业分布
   • 持仓特点（亮点/风险）

3. 业绩表现
   • 8个时间段（1周-1月-3月-6月-今年-1年-2年-3年）
   • vs 同类平均 / 跟踪标的 / 沪深300
   • 四分位排名

4. 风险评级
   • 风险等级（R1-R5）
   • 风险来源（市场/集中度/流动性/汇率/经理）
   • 最大回撤估算

5. 综合评价
   • 7维度评分（100分制）
   - 收益能力 (20分)
   - 选股能力 (15分)
   - 风险控制 (20分)
   - 流动性 (10分)
   - 费率成本 (10分)
   - 基金经理 (15分)
   - 行业前景 (10分)

6. 投资建议
   • 当前占比 vs 目标配置
   • 增持/持有/减持判断
   • 具体操作建议
```

### 组合分析方法

```
1. 组合信息收集
   • 基金代码 + 名称 + 金额 + 占比 + 近1年收益 + 风险等级

2. 资产配置分析
   • 美股/中概/港股/A股/债券/REITs/现金占比
   vs 理想配置（高风险/中风险/低风险）

3. 组合收益分析
   • 加权计算：Σ(单只收益 × 该基占比)
   • 夏普比率：超额收益 / 波动率

4. 组合风险分析
   • 最大回撤预估（基于配置和历史）
   • 流动性风险评估（正常/限大额/暂停）
   • 风险暴露（市场/行业/货币）

5. 组合评级
   • 6维度评分（收益/选基/风控/区域/资产/流动性）
   • 综合评级：A-E级

6. 优化建议
   • 短期（1-2月）：具体操作清单（赎回什么 + 申购什么）
   • 中期（3-6月）：定投策略 + 债券配置
   • 长期（1-3年）：目标配置 + 投资原则
```

## 🚨 风险警示

### 此skill的局限性

1. **数据时效性**
   - 数据抓取是一次性的，非实时更新
   - 净值、仓位、排名可能已变化

2. **分析深度**
   - 基于公开数据，缺乏内部信息
   - 无法分析基金经理决策逻辑
   - 无法分析市场情绪/博弈

3. **预测能力**
   - 不承诺未来业绩
   - 不保证历史持续
   - 不排除黑天鹅事件

4. **替代专业顾问**
   - 不替代专业投资顾问
   - 不具备职业投资资质
   - 不能承担投资责任

### 使用建议

```
✅ 适合：
   - 投资金额 < ¥10,000（个人小资金）
   - 学习基金分析方法
   - 自主投资决策参考

⚠️ 不适合：
   - 投资金额 > ¥10,000（大额投资）
   - 依赖建议全盘接受
   - 不愿了解投资风险

❌ 严禁：
   - 向他人推荐投资决策
   - 承诺收益或安全
   - 提供经理/机构联系方式
```
