# 基金深度分析 Skill

**技能名称**: fund-deep-analysis
**版本**: 1.0
**创建时间**: 2026-03-03
**适用场景**: 基金研究、组合评估、风险分析

---

## 📖 技能概述

本skill提供完整的基金深度分析框架，基于真实数据源（天天基金网/东方财富），实现单基金和组合的全面评估。

### 核心能力

- ✅ 单基金深度分析（业绩、持仓、风险、评级）
- ✅ 组合整体评估（收益、风险、配置健康度）
- ✅ 多基金对比分析
- ✅ 风险暴露量化评估
- ✅ 优化方案生成

### 数据来源

```
主要数据源：
• 天天基金网: https://fund.eastmoney.com/{基金代码}.html
• 东方财富网: 同天天基金网

备用数据源：
• Jina API: https://r.jina.ai/http://fund.eastmoney.com/{基金代码}.html
• WebFetch: OpenClaw内置工具
• Browser: 复杂页面需要时使用
```

#### 2.4 风险评级

##### 风险等级标准

```markdown
风险评级分类：

R5 - 极高风险：
• 行业单一（前10持仓<5家公司）
• 集中度>70%
• 暴涨暴跌股票占比高
• 新兴市场/小盘股为主

R4 - 高风险：
• 集中度40-70%
• 单一行业50-80%
• QDII/海外波动大
• 科技/生物医药主题

R3 - 中高风险：
• 集中度25-40%
• 行业分散3-5个
• 混合配置常见

R2 - 中等风险：
• 宽基指数（沪深300、标普500）
• 集中度<25%
• 包含防守资产

R1 - 低风险：
• 债券/货币基金
• 保本/固定收益
```

##### 风险来源分析

必须分析的风险维度：

```
1. 市场风险：
   主要投资哪个市场的基金
   该市场的宏观经济风险
   政策风险（监管、税收）

2. 集中度风险：
   前10大持仓占比
   单只股票最大占比
   行业集中度

3. 流动性风险：
   暂停申购/赎回
   限大额交易
   QDII额度限制

4. 汇率风险（QDII基金）：
   人民币/美元/港币波动

5. 基金经理风险（主动管理基金）：
   管理规模大/小
   历史业绩
   决策透明度
```

##### 风险量化评估

```
最大回撤估算（基于历史数据或同类）：
• 保守估计：-15% to -25%
• 激进估计：-25% to -40%
• 极端情况：-40% to -60%（纳指、生物科技等）

波动率估算（基于基金类型）：
• 宽基指数：15-20%
• 行业主题：20-30%
• QDII海外：20-30%
• 生物科技/小盘股：30-40%
```

组合近1年收益 = Σ(贡献) ≈ 20.22%
