# Fund Playbook

Use this file when the user wants a fund allocation, 定投 plan, beginner fund portfolio, or a direct answer to `基金怎么买`.

## Default assumptions

- mainland China retail investor
- no leverage
- use public mutual funds or ETFs only
- prefer broad index funds over narrow themes
- use bond and money-market funds to control drawdown
- keep the first version simple enough to maintain

## Horizon-first templates

### Under `1 year`

Default:

- `50-70%` money-market fund
- `30-50%` short-duration or pure bond fund
- `0%` equity fund

Use this when the user may need the money soon or says `求稳`.

### `1-3 years`

Default:

- `20-35%` broad China equity index fund
- `45-60%` short-duration or pure bond fund
- `10-20%` money-market fund
- optional `0-10%` overseas broad-index QDII fund

Use this when the user can accept moderate fluctuation but wants capital stability first.

### More than `3 years`

Default balanced version:

- `35-45%` broad China equity index fund
- `15-25%` overseas broad-index QDII fund
- `25-35%` bond fund
- `10%` money-market fund

Default growth version:

- `50-60%` broad China equity index fund
- `15-25%` overseas broad-index QDII fund
- `15-25%` bond fund
- `5-10%` money-market fund

Use the balanced version for most users when risk preference is unclear.

## Building blocks

Use categories first. Only name specific funds after verifying current fees, size, and mandate.

- `Broad China equity index`: choose one low-fee fund tracking a diversified index such as `沪深300` or `中证A500`
- `Overseas broad index QDII`: choose one low-fee fund tracking a broad U.S. or global index
- `Bond fund`: prefer pure bond or short-duration bond funds for beginners
- `Money-market fund`: use for liquidity and staged entry, not for long-term growth

Avoid recommending multiple funds that all track nearly the same index.

## Deployment rules

### For lump-sum capital

- if volatility tolerance is low, deploy in `3-6` tranches
- if market conditions are unusually unstable, prefer slower deployment over guessing a bottom

### For monthly investing

- keep a fixed contribution date
- change the plan only when objectives or risk tolerance change
- do not chase last month's top-performing fund

## Risk rules

- keep any single sector or theme fund at `<=20%`
- review once per quarter unless there is a major event
- rebalance when a sleeve drifts by about `10%` from target weight
- if the user cannot tolerate a `15-20%` drawdown, reduce equity exposure
