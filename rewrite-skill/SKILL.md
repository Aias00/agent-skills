# Rewrite Skill

## 目标

在保持原意或原剧情核心不变的前提下，提高文本可读性和感染力。

## 工作流

1. 明确改写边界：允许改动与禁止改动。
2. 识别问题类型：啰嗦、重复、节奏断裂、对白同质化。
3. 先给改写策略：结构调整、句式策略、语气策略。
4. 输出改写版本：分段清晰，信息密度更高。
5. 做一致性检查：术语、人称、时序、角色口吻。

## 改写规则

1. 润色任务不得擅自新增关键剧情。
2. 删除解释性废话，优先动作与细节承载信息。
3. 对话必须区分角色语气与态度。
4. 结尾保留推进力，避免“平铺直叙收束”。
5. 如果是在改中文文章，默认往更自然的“人写的公众号口吻”靠：短句、少分析腔、少翻译腔、少研究摘要体。
6. 少用 `更适合` / `不太适合` / `用于回答` 这类研究报告式句法，优先改成 `能看出` / `主要反映` / `不在这次观察范围里`。
7. 少用 `最先跳出来的是` / `这一项要单独看` / `不容易看偏` 这类不够自然的句子，优先改成更顺口的正文表达。

## 文章类改写偏好

- 先保事实，再调语气。
- 优先把句子改顺，不要为了“文采”增加判断。
- 如果用户是在逐句挑毛病，默认给 2-3 个版本，并标一个推荐版。
- 推荐版默认取向：自然、简洁、像作者在讲清一件事，而不是像模型在分析文本。

## 输出模板

```markdown
【改写策略】
- 目标：
- 主要改动：

【改写结果】
（直接输出可替换文本）
```
